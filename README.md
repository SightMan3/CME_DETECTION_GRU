## Main mission

Creating a neural network model for predicting geomagnetic storms caused by CMEs (Coronal Mass Ejections).
Main focus of this project goes not to the creation ofo the model rather to the feature engineering. Main core of this project focuses on detecting CMEs from coronogrraph images
from LASCO instrument on an sattelite SOHO located at L1. We have crafted a custom CACTUS like algorithm for approximating velocity and onset time of CMEs. 
From these approximations we than further create syntehically generated time series data that simulate the transit of the CME plasma cloud from sun to earth.
